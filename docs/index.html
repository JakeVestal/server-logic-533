Use the instructions below on how to properly create a PAT.

A green check means you are connected and set up. A red X means you should contact the instructor for troubleshooting. It is probably your PAT, which needs read and write permission on your repo.

How to create your PAT

  1. Sign in to GitHub.
  2. Open github.com/settings/personal-access-tokens/new. Use this page. Do not use the classic token page.
  3. Token name: duke-533. Description can stay blank.
  4. Resource owner: your own account, not an organization.
  5. Expiration: choose Custom and pick a date after this course ends. If you do not know that date, pick a date 180 days from today. Do not leave the default, and do not pick 7 or 30 days.
  6. Repository access: Only select repositories. Select the one repository you created for this class. Do not select All repositories.
  7. Open Repository permissions. Find Contents. Set it to Read and write. Leave every other permission on No access.
  8. Click Generate token.
  9. Copy the token immediately. It starts with github_pat_ and GitHub shows it only once. If you leave the page without copying it, generate a new one.
  10. Send the instructor a Teams message with two things: the token, and the repository URL from the green Code button. It looks like https://github.com/your-username/your-repo. Do not send a github.io address.

Do not commit the token, and do not paste it into the repository or the class chat. If your row is a red X after you have been added, the token on file cannot write to that repository. Make a new one with Contents set to Read and write on that exact repository, and send it to the instructor.
